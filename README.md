# Dikshi Technologies — Cloth & Fancy SmartPOS

> Next-generation high-velocity POS billing, multi-attribute cloth tagging, size & color matrix inventory, and real-time showroom intelligence designed specifically for silk saree emporiums, readymade apparel boutiques, and fashion showrooms.

---

## 🌟 Key Features

- **⚡ Sub-Second Counter Billing (<0.8s)**: Offline-first high-concurrency checkout with instant barcode lookup and split Cash/UPI payments.
- **🏷️ Multi-Attribute Cloth & Zari Tagging**: Dynamic barcode hangtag generation encoding zari purity (Pure/Half Fine), weaver origin, and unstitched blouse pieces.
- **✂️ Tailor Slips & Alteration Hub**: Direct billing-to-workshop sync for fall-pico, blouse stitching, sleeve adjustments, and automated WhatsApp ready notifications.
- **📈 Deadstock & Saree Aging Intelligence**: Visual aging alerts (30/60/90+ days) preventing capital lock-in during peak wedding and festive seasons.
- **💻 Desktop POS Simulator**: Embedded interactive Windows 11 terminal simulator with responsive bidirectional scrolling on mobile.
- **📱 Cross-Platform Reach**: Ready for Windows 10/11 desktops, iOS/Android mobile aisle checkout, and thermal receipt printing.
- **🖨️ 80mm GST Thermal Bill Printing**: Instant calculation of SGST (2.5%) and CGST (2.5%) apparel tax with dynamic UPI QR code.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/gokulavasanpk/dikshi-technologies-smartpos.git

# Navigate to project directory
cd dikshi-technologies-smartpos

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
